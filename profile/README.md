[ShipThis](https://github.com/shipth-is/cli) is a command-line tool which builds and publishes Godot games to the App Store and Google Play

## Community

💬 Join us on [Discord](https://discord.gg/gPjn3S99k4) to chat with the ShipThis community, discuss the release, or ask questions.

⭐️ Help us out by [starring ShipThis on GitHub](https://github.com/shipth-is/cli).

## Repos

- [shipth-is/action](https://github.com/shipth-is/action): GitHub action for running ShipThis
- [shipth-is/cli](https://github.com/shipth-is/cli): CLI to build and publish Godot games to the App Store and Google Play
- [shipth-is/go-android](https://github.com/shipth-is/go-android): Android companion app for the CLI - streams debug logs back to the terminal
- [shipth-is/godot-3.x-builds](https://github.com/shipth-is/godot-3.x-builds): Nightly builds of the Godot 3.x branch
- [shipth-is/godot-android-sdk-upgrade](https://github.com/shipth-is/godot-android-sdk-upgrade): Android SDK 35 Patched Releases of Godot 4.x
- [shipth-is/godot-export-presets](https://github.com/shipth-is/godot-export-presets): JS library to read and write Godot export_presets.cfg files
- [shipth-is/godroid-builder](https://github.com/shipth-is/godroid-builder): Patched and namespaced builds of the Android Godot library
